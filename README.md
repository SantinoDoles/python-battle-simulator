# Python Battle Simulator

A turn-based combat game built with Python where players battle randomly selected enemies.

The game features attacking, defending, healing potions, critical hits, and randomized enemy damage. Players must use strategy to defeat their opponent while managing their health.

## Features

- Turn-based combat system
- Random enemy selection (Goblin or Skeleton)
- Unique enemy health and attack damage
- Critical hits that deal double damage
- Defending to reduce incoming damage
- Healing potions with limited uses
- Randomized enemy attacks and misses
- Victory and game-over conditions

## Technologies & Skills

- Python 3
- Variables and data types
- Conditional statements (if, elif, else)
- While loops
- Functions
- Lists
- Random number generation
- User input and input validation
- Arithmetic and comparison operators

## How to Play

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the game using:

   `python main.py`

5. Enter your character's name.
6. Choose an action each turn:
   - 1: Attack the enemy
   - 2: Defend against incoming damage
   - 3: Use a healing potion
7. Defeat the enemy before your health reaches zero!
